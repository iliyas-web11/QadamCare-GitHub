# QadamCare

**БЦС (ДЦП) бар балалардың жүріс деректерін салыстыруға арналған браузерлік прототип.**

AI-Sana Shakarim Solveathon: AI & Medicine 2026 жобасы. Интерфейс қазақ, орыс және ағылшын тілдерінде жұмыс істейді.

> QadamCare — маманға арналған көмекші зерттеулік құрал. Диагноз қоймайды, ем тағайындамайды және клиникалық тексеруді алмастырмайды.

## Мүмкіндіктер

- Baseline, Verbal және VR жағдайларындағы 6 CSV файлын жүктеу, ондық үтір мен NaN мәндерін өңдеу.
- Пациенттер бойынша графиктер, орташа мәндер, өзгерістер және жарамды циклдер саны.
- Пациент бойынша бөлінген GroupKFold ML: Logistic Regression және Nearest Centroid. Дәлдік жүктелген деректермен есептеледі.
- Әр пациентке бөлек невролог/психолог мәртебелері және МДТ бағыты.
- Жергілікті видео/камерадан 2D қозғалысты бақылау, синтетикалық жүріс демосы, ROM және зерттеулік салыстыру белгілері.
- 3D анатомиялық қаңқа, GVS көрсеткіштері және компенсация белгілері.
- Дәрігер және ата-ана демо-рөлдері, үлкен қаріп және браузер қолдаса дауыстап оқу.
- Графиктері бар HTML есеп, браузердің басып шығару терезесі арқылы PDF, CSV, құрылымды хаттама және FHIR JSON экспорты.

## Жылдам іске қосу

Бұл жобаға Node.js, npm немесе құрастыру қажет емес. **Python 3** жеткілікті.

```bash
python -m http.server 8767 --bind 127.0.0.1
```

Команданы репозиторийдің түбірінде орындап, [http://127.0.0.1:8767](http://127.0.0.1:8767) мекенжайын ашыңыз. Кей жүйелерде `python` орнына `python3` қолданылады.

Windows-та `Start-QadamCare.cmd` файлын екі рет басуға болады. Сервер терезесін жұмыс барысында ашық ұстаңыз. 8767 порты бос болуы керек.

1. «Демо: Дәрігер» немесе «Демо: Ата-ана» таңдаңыз.
2. Кіріктірілген синтетикалық деректермен танысыңыз немесе өзіңіздің алты CSV файлыңызды жүктеңіз.
3. Пациент пен бөлімді таңдаңыз. Видео бөлімі деректер жүктелгеннен кейін көрсетіледі.
4. Видео мүмкіндігін қауіпсіз тексеру үшін синтетикалық демо батырмасын қолданыңыз.

`index.html` файлын тікелей ашқанда негізгі функциялар жұмыс істей алады, бірақ 3D үшін HTTP/HTTPS қажет. Сондықтан жергілікті сервер ұсынылады.

## CSV форматы

Бірге жүктелетін файл атаулары:

```text
Discrete_Parameters_Baseline.csv
Discrete_Parameters_Verbal.csv
Discrete_Parameters_VR.csv
Kinematics_Kinetics_Baseline.csv
Kinematics_Kinetics_Verbal.csv
Kinematics_Kinetics_VR.csv
```

Бөлгіш — `;`, ондық бөлгіш — үтір немесе нүкте, бос мән — `NaN`. `side` бағаны `LEFT`, `RIGHT`, `L`, `R` мәндерін регистрге тәуелсіз қабылдайды. `subject` — иесіздендірілген пациент коды. Кинематика файлдары қолданба күтетін 51 нүктелі сигнал бағандарын қамтуы тиіс.

Кіріктірілген демо — 29 синтетикалық пациент; ол клиникалық зерттеу деректері емес. KU Leuven CSV файлдары бұл репозиторийге қосылмаған. Егер оларды кейін қоссаңыз, дереккөздің CC BY-NC-SA 4.0 шарттарын сақтаңыз; мәліметтер `THIRD_PARTY_NOTICES.md` ішінде.

## Офлайн жұмыс және сыртқы тәуелділіктер

| Мүмкіндік | Қажеттілік |
| --- | --- |
| CSV/демо, GroupKFold ML, МДТ, чеклист, экспорт | Файлдар ашылған соң браузерде жергілікті жұмыс істейді |
| Синтетикалық видео демосы | Офлайн |
| Нақты видео/камерадағы MediaPipe | Модель мен WASM/CDN кітапханасын алғаш жүктеу үшін интернет |
| 3D қаңқа | Жергілікті HTTP/HTTPS сервері және model-viewer кітапханасын жүктеуге интернет |
| Камера | Рұқсат және HTTPS немесе localhost |
| Қаріптер | Google Fonts; қолжетімсіз болса жүйелік қаріп |
| Дауыстап оқу | Браузер/операциялық жүйеде қажетті тілдің дауысы |

Видео мен CSV қолданба кодымен серверге жүктелмейді. Сыртқы CDN сұраулары кітапхана/модель/қаріп ресурстарын жүктеу үшін пайдаланылады. Толық офлайн орнату пакеті немесе PWA кэші бұл нұсқада жоқ.

## Прототип шектеулері

- Аккаунттар браузердің `localStorage` жадындағы демо. Бұл серверлік авторизация немесе медициналық қолжетімділікті қорғау жүйесі емес.
- Damumed/eDensaulyq API-мен тікелей байланыс жоқ. Экспорт — өзара үйлесімділік прототипі; нақты МАЖ-ға енгізу бөлек тексеруді қажет етеді.
- Видео — бір камералы 2D бақылау. Бүйірден 90° түсіру керек; ракурс, көріну және кадр жиілігі нәтижеге әсер етеді. Ол Vicon 3D-ні алмастырмайды және буын күш моменттерін өлшемейді.
- ROM/ырғақ белгілерінің шектері — прототиптің зерттеулік шектері, расталған балалар клиникалық нормасы емес.
- 3D модель — жалпы анатомиялық көрініс, пациенттің жеке 3D реконструкциясы емес.
- Нақты пациенттердің жеке деректерін немесе танылатын видеоларын жарияламаңыз; демонстрацияға қауіпсіз ересек/команда материалдарын пайдаланыңыз.
Бұл дайындық кезінде GitHub репозиторийі жасалған жоқ және сайт жарияланған жоқ.
